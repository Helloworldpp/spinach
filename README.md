# 一杆定胜负

一个黑金台球赛事风格的好友下注记录工具，支持胜负局、猜比分、封盘、赛果结算、滚存和往期账簿。

胜负局与猜比分使用两条完全独立的奖池链：

- 胜负局只从本局新下注中取 20% 作为冠军奖金；剩余 80% 加上既有胜负滚存，由猜中胜者的人按下注比例分配。无人猜中则可分奖池滚入下一场胜负局。
- 猜比分不抽冠军奖金；本局新下注加上既有比分滚存，全部由精确命中者按下注比例分配。无人命中则整池滚入下一场猜比分。
- 滚存只进入下一场的同一玩法，不会重复抽取冠军奖金，也不会在两个玩法之间互转。

## 票据与历史

- 每次保存下注都会生成一张 `1080 × 1440` 下注票据，记录下注人、助威备注、选择、金额、当时奖池、预估返还、预估净赢与倍数。
- 封盘和结算会分别生成封盘快照与结算票据；所有版本的票据元数据均保存在本机数据库中，可随时重新生成、下载或复制图片。
- 修改下注会生成新版本，旧票据标记为“已更新”；删除开放中的下注会把其最新票据标记为“已取消”。
- 所有比赛、下注和结算默认永久保留在往期账簿中，历史详情可查看逐笔预测、金额、命中情况和最终返还。

## 删除保护

- 删除密码为 `1123`，密码由本地后端校验。
- 单笔下注只能在比赛开放期间删除。
- 整场比赛会连同下注、结算和票据永久删除且无法恢复。为保护滚存链，只能从最新一场开始按时间倒序删除。
- 这是面向可信局域网的简易管理密码，不应当作公网环境的账号安全方案。

## 本地运行

```bash
npm install
npm run dev
```

本地开发时，结构化记录保存在本机的 Cloudflare D1 开发数据库中；刷新或重启开发服务不会清空。`.openai/hosting.json` 声明 Sites 项目与数据库绑定。
